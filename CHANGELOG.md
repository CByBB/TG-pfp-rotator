# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-09-21

### Added

- Multi-user Telegram bot with phone login, inline code pad, and 2FA
- Profile photo gallery with resize/crop and interval rotation
- Pause, resume, interval, status, and donate commands
- File-based storage (no database)
- MIT license, security policy, contributing guide, and CI
