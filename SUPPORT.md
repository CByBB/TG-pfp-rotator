# Support

## How to get help

1. Read the [README](README.md) setup and command list.
2. Search [existing issues](https://github.com/CByBB/TG-pfp-rotator/issues).
3. Open a new issue with your Node.js version, OS, and the steps you took.

## What we can help with

- Setup (`pnpm`, `.env`, BotFather, `api_id` / `api_hash`)
- Bot commands and login / gallery / rotation behavior
- Bugs and feature requests

## What we cannot help with

- Recovering a Telegram account or session you lost
- Bypassing Telegram limits, bans, or 2FA
- Hosting, VPS, or reverse-proxy setup for a specific provider

## Security

Use [SECURITY.md](SECURITY.md). Do not post tokens, session strings, or 2FA passwords.
